## Overview
This Weather App is a simple and user-friendly application that provides real-time weather information using APIs. The app fetches live weather data from an online weather service and displays details such as temperature, weather conditions, humidity, wind speed, and location information.

## Features
Real-time weather updates using API integration

Search weather information for any city

Displays temperature, humidity, and wind speed

Shows weather conditions like sunny, rainy, or cloudy

User-friendly and responsive interface

Fast and accurate data fetching

Dynamic weather icons and information display

Easy navigation and simple design
